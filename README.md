# FemmeRevive — Static site (GitHub Pages)

Static clone of the FemmeRevive wellness & beauty site for deployment on GitHub Pages.

## Structure

```
femme-revive/
├── index.html
├── css/style.css
├── js/main.js
├── images/          ← add client photos here
└── README.md
```

## Deploy

1. Create a GitHub repo (e.g. `femme-revive`).
2. Upload these files to the root (or `docs/` folder).
3. Settings → Pages → Deploy from branch `main` / root (or `/docs`).
4. Site will be live at `https://YOURUSER.github.io/femme-revive/`.
